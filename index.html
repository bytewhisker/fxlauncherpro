Common questions

Things editors ask.

Which Premiere Pro versions are supported?
Premiere Pro 2024 and 2025 on both Windows and macOS. CEP-based extensions install through the standard ZXP/ZIP route — instructions ship with the download.
Do I need both the extension and the tray app?
The CEP extension does all the work inside Premiere. The companion tray app (FX Spell Book) is what gives you the true global Alt+Space hotkey. You can use the extension on its own, but the tray app is what makes it feel instant.
Is the tray app available on macOS?
The CEP extension runs natively on both platforms. The global hotkey tray app currently ships for Windows, with macOS support coming as a free update.
How is this different from other launchers?
FX Launcher Pro uses true fuzzy search (Fuse.js), stays responsive on large effect libraries, includes a system-wide hotkey via the companion tray app, and is designed for fast daily editing workflows.
